# BUILD.FUN.FREE Skills

Reusable agent workflow skills for the BFF portfolio. Used by Paperclip agents via Claude Code.

## Categories

- `sprint/` — Engineering workflow (think → plan → build → review → test → ship → reflect)
- `content/` — Content pipeline (research → draft → edit → publish)
- `knowledge/` — Vault maintenance (hygiene, stale detection, compiled truth)
- `ops/` — Operations (deploy check, agent debug, infra audit, distribution)

## Install

Import via Paperclip dashboard or:
```bash
npx skills add bravura-studio/skills
```
